# Little Learners 3.0 — Smart Learning Platform

Android WebView app designed for a free GitHub Actions build.

## Build
The repository includes `.github/workflows/build-apk.yml`. GitHub Actions builds a debug APK and uploads it as the `LittleLearners-APK` artifact.

## v3 foundation
- Preschool vocal learning
- Learner profile and level/grade selection
- Primary, JSS, SSS and tertiary catalogue architecture
- Subject → topic → lesson flow
- Quiz engine with objective questions
- Educational games and Fun Zone
- Parent progress area
- Offline local progress storage
- Android Text-to-Speech bridge

## Curriculum note
The catalogue is an extensible foundation. Curriculum content should be reviewed and expanded against the applicable official curriculum before public academic claims are made.
